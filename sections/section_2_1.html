Section 2.1: Methods and Parameters

Part 1: Characteristics of Object-Oriented Programming

Question: What are the five characteristics of an object-oriented approach to programming?

  • 1. Encapsulation: Bundling data and methods inside objects to hide implementation details.
  • 2. Abstraction: Exposing only essential features while hiding complexity.
  • 3. Inheritance: Creating new classes from existing ones to promote code reuse.
  • 4. Polymorphism: Allowing objects of different types to be treated uniformly.
  • 5. Message Passing (or Communication): Objects interact via method calls to perform behavior.

Question: What are two reasons for controlling access to members of objects and how does Java implement control?

  • To protect data integrity and prevent unauthorized access.
  • To enforce modular design by hiding implementation details.
  • Java uses private, protected, public, and default access modifiers to implement access control.

Question: What are two ways of re-using classes?

  • Inheritance – extend existing classes to create specialized subclasses.
  • Composition – include existing classes as member objects within new classes.

Part 2: Late Binding

Question: How does late binding enable upcasting and polymorphism?

  • Late binding (dynamic method dispatch) allows the JVM to determine at runtime which method to invoke based on the actual object type.
  • Upcasting: a subclass object can be referenced by a superclass variable, while the correct overridden method executes dynamically.
  • This enables polymorphism: different object types can be used interchangeably with consistent behavior.

Part 3: Containers and Generics

Question: What is a container? What is an advantage of using a container?

  • A container is an object that holds and organizes multiple other objects, e.g., ArrayList, HashMap.
  • Advantage: simplifies management of groups of objects and provides generic operations like iteration, sorting, and searching.

Question: What is 'parameterized types/generics'? How does it eliminate the need for downcasting?

  • Generics allow classes and methods to operate on objects of specified types while maintaining type safety.
  • They eliminate downcasting by ensuring compile-time type checks, so retrieved objects are already of the expected type.

Question: Where in memory does Java create objects?

  • Objects are created on the heap, and references to them are stored in stack memory variables.

Part 4: Exception Handling and Threads

Question: What is the function of exception handling and how does Java reinforce consistent use?

  • Exception handling manages runtime errors, preventing program crashes.
  • Java enforces checked exceptions, requiring methods to declare or handle them, ensuring consistent error management.

Question: What are the functions of threads in single-processor and multi-processor environments?

  • Single-processor: threads enable multitasking by time-slicing the CPU.
  • Multi-processor: threads can run in parallel, improving performance for concurrent tasks.

Part 5: Client/Server Systems and Web Programming

Question: What is the primary idea of a client/server system?

  • A server provides resources or services; clients request and consume them over a network.

Question: How did Web serving lead to client-side programming?

  • Web servers could only provide static pages; to handle dynamic content and interactive features, processing moved to the client side (e.g., JavaScript).

Question: What is CGI programming and its major shortcoming?

  • CGI (Common Gateway Interface) allows server-side scripts to process client requests.
  • Shortcoming: each request spawns a new process, which is resource-intensive and slower.

Question: Why is client-side programming efficient for the Web?

  • Reduces server load and network traffic by handling computations and interactions locally on the client machine.

Question: What is a plugin?

  • A plugin is a software module that extends the capabilities of the client application (e.g., browser plugins for multimedia support).

Question: What is a scripting language?

  • A high-level language used to automate tasks, often interpreted rather than compiled, e.g., JavaScript or Python.

Question: Compare scripting languages to Java for Web page needs.

  • Scripting languages execute quickly on the client, are flexible for lightweight tasks, and do not require compilation. Java is more structured, type-safe, and compiled to bytecode, offering stronger portability and performance.

Question: What are the issues of Intranet vs Internet programming?

  • Intranet: controlled, secure environment; easier deployment.
  • Internet: public exposure, higher security risks, scalability and bandwidth challenges.

Question: What is the role of Java in server-side programming?

  • Java provides robust, platform-independent server-side solutions, including servlets, JSP, and enterprise frameworks for scalable web applications.
