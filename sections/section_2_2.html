Section 2: Objects and Classes in Java

Part 1: Objects and Primitive Types

Object vs Handle

  • Object: The actual data stored in memory (on the heap).
  • Handle (Reference): A variable that stores the address of the object.

Memory Areas in Java

  • Registers: Fast CPU storage (not directly controlled by programmer).
  • Stack: Stores primitive values and object references.
  • Heap: Stores objects.
  • Constant Storage: Stores constant values (e.g., string literals).
  • Non-RAM Storage: Persistent storage (e.g., files, databases).

Nine Primitive Types

  • boolean
  • char
  • byte
  • short
  • int
  • long
  • float
  • double
  • void

High-Precision Classes (No Primitive Equivalent)

  • BigInteger
  • BigDecimal

Scope: Primitives vs Objects

  • Primitives are destroyed when leaving scope.
  • Objects remain until garbage collected (reference may go out of scope first).

Part 2: Classes, Fields, and Methods

Definitions

  • Class: Blueprint defining data and behavior.
  • Field: Data member inside a class.
  • Method: Function that defines behavior.

Default Values vs Local Variables

  • Class member primitives receive default values (e.g., int → 0).
  • Local variables must be explicitly initialized before use.

Fundamental Parts of a Method

  • Access modifier
  • Return type
  • Method name
  • Parameter list
  • Method body

Part 3: Namespaces, import, static

Naming Convention for Public Libraries

  • Use reverse domain naming (e.g., com.company.project).

Purpose of import

  • Allows use of classes without fully qualifying package names.

Functions of static

  • Shared across all objects of a class.
  • Can be accessed without creating an instance.
  • Used for utility methods and shared data.

Part 4: Compiling and Running Java

How HelloDate.java Prints the Date

  • Creates a Date object.
  • Calls System.out.println() to display it.

public static void main(String[] args)

  • public: Accessible to JVM.
  • static: No object needed to invoke.
  • void: Returns nothing.
  • main: Entry point.
  • String[] args: Command-line arguments.

Why main is static

  • JVM must call it without creating an object first.

Compile & Run

  • Compile: javac HelloDate.java
  • Run: java HelloDate

Part 5: Documentation and Coding Style

Standard Coding Style

  • Class names: Capitalized (CamelCase).
  • Method/variable names: lowerCamelCase.
  • Braces on same line.
  • Indentation consistent (4 spaces).
  • Use Javadoc comments for classes and methods.
